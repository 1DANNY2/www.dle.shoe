# Danny's Shoe Store

A responsive front-end e-commerce website for Danny's Shoe Store.

## Included
- Responsive home page with uploaded cover/logo image
- Product catalogue and category filters
- Search
- Shopping cart with local storage
- WhatsApp checkout
- New arrivals and offers
- About section
- Booking / fitting form that opens WhatsApp
- Contact section
- Settings: dark mode, currency and cart preference
- Email, Facebook name and WhatsApp/contact number
- Mobile-friendly navigation

## Run
Open `index.html` in a browser. No server is required for the basic front-end.

## Deploy
Upload the entire folder to Netlify, GitHub Pages, or another static hosting service. Keep the `assets` folder next to `index.html`.
